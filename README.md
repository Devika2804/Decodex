# Decodex – AI-Powered Medical Report Translator

## Overview

Decodex is an AI-powered application that converts complex radiology reports into simple, patient-friendly language. The goal is to help patients better understand their medical reports without needing medical expertise.

This project was developed during the Forge AI Hackathon hosted by Nova Benefits × 5C Network.

## Problem Statement

Radiology reports often contain complex medical terminology that can be difficult for patients to understand. This can lead to confusion and anxiety.

Decodex addresses this problem by translating technical medical language into clear and easy-to-understand explanations.

## Features

* Simplifies complex radiology reports into plain language
* Supports 12+ languages
* WhatsApp-based report delivery
* User-friendly interface
* AI-powered medical report interpretation

## Tech Stack

* Claude AI
* Lovable
* Cursor
* n8n

## How It Works

1. User uploads or enters a radiology report.
2. AI analyzes the report content.
3. Medical terminology is converted into simple language.
4. The translated report is generated in the selected language.
5. The report can be delivered through WhatsApp.
